# Iteration 3 검증 후보

상태: 설계에 따른 후보를 기록하는 단계. 공식 검증 범위 확정·실행 허락이나 성능 측정 허락을 뜻하지 않는다.

| 항목 | 목적·통과 기준 |
| --- | --- |
| 디렉터리 | GET /static/와 실제 하위 디렉터리 요청이 403. 목록이나 index.html을 보내지 않음 |
| 심볼릭 링크 | 파일 링크·중간 디렉터리 링크·끊어진 링크를 따라 파일을 제공하지 않음. 루트 내부/외부 대상 모두 포함 |
| 일반 파일 | 링크가 없는 루트 내부 일반 파일은 실제 바이트와 MIME·Content-Length가 일치 |
| 회귀 | 기존 /·/hello·/echo 응답 정책 유지 |

검증 후보는 경로 해석·전송·동적 핸들러 설계 선택 후 추가한다. 오류 코드의 상세 매핑, 루트 자체의 링크 처리, 이름/경로 경계, 파일 변경 중 송신 등 미결정 사항은 아직 통과 기준으로 확정하지 않는다.
## 경로 해석·루트 시작 검증 후보
- %20 및 인코딩된 파일명은 한 번 디코딩해 매핑한다. 쿼리는 파일 경로에 포함하지 않는다.
- %2F, 역슬래시, NUL·제어문자는 400. .·.. 세그먼트는 원문/인코딩 양쪽에서 403.
- 이중 인코딩은 한 번만 해석한다. 남은 %HH를 다시 해석해 탈출하지 않는다.
- CLI 루트의 링크는 허용하고, 없는 루트·일반 파일 루트·열 수 없는 루트는 오류 출력 후 시작 중단.
- 기존 동적 경로의 디코딩/정규화 정책은 바뀌지 않는다.
## 전송·MIME·동적 핸들러 검증 후보
- 빈 파일·16KiB 경계 전후·버퍼보다 큰 파일의 fstat 크기, Content-Length, 실제 전송 바이트 일치.
- 부분 read/send, EINTR, 클라이언트 종료 시 실패 전파와 파일 FD 회수.
- html/htm/css/js/png/jpg/jpeg 및 대문자 확장자와 미지정 확장자의 MIME 일치.
- /greet의 서로 다른 name에 따라 응답이 달라지고 실제 UTF-8 바이트 수와 Content-Length 일치.
- 파일 변경 관련 기준은 사용자 정책 선택 후 추가한다.
## 추가 확정 기본 검증 후보
- /static은 404, 반복 슬래시 400, 끝 /와 디렉터리 403. POST 정적 요청은 존재 여부와 무관하게 405 + Allow: GET.
- 없음/중간 파일 404, 링크/비정규 파일/권한 403, 너무 긴 이름 414, 내부 오류 500.
- 최초 길이 이후 증가분은 보내지 않음. 조기 EOF·파일 읽기 오류·클라이언트 송신 실패는 불완전 응답으로 종료하고 파일/연결 FD를 회수함. 두 번째 HTTP 응답을 붙이지 않음.
- 불변 파일 게시·읽기 권한·변경 가능 계정과 파일/디렉터리 변경 제한은 문서 검토 및 기본 기능/자원 검증에 포함.
- 쿼리를 구분한 뒤 디코딩: %26/%3D는 새 구분자로 처리하지 않음. 디코딩된 키 중복 name도 400. 검사 범위는 사용자 선택 후 확정.
- 광범위한 쿼리 조합·퍼징은 안정화 단계에서 확대하며 이번 기본 성공/실패 검증을 대체하지 않음.
## 쿼리 기본 검사 기준과 체크포인트 재검토
모든 키·값에 UTF-8과 U+0000~001F/U+007F~009F 금지를 현재 기준으로 적용한다. 알려진/알 수 없는 키·값의 잘못된 %, UTF-8, NUL·제어문자, 과잉 인코딩·대리 코드 포인트·범위 초과를 기본 실패 사례에 포함한다.
검증 범위 검토 시 인코딩 지원·금지 제어문자 범위의 확대 여부를 사용자에게 다시 제시한다. 현재 구현 기준을 영구 정책으로 간주하거나 검사 범위를 자동 확대하지 않는다.

제안 명령: make test(ASan/UBSan 포함 7개 바이너리), make verify(3개 E2E). 현재 모두 미실행이다. 실제 sanitizer 런타임 성공·누수 없음·DoD 충족으로 주장하지 않는다.
루트 권한/ACL/WSL 마운트의 실제 운영 계약 충족 검사는 위 임시 fixture 검사와 다르며 아직 하지 않았다. 프로젝트 권한을 바꾸지 않는다.

### 포함/제외와 남은 위험
- 실제 파일 truncate/증가와 rename은 임시 파일을 사용하는 단위 테스트 소스로 준비했다. 대용량 전송 중 동시 쓰기 경합 전체를 증명하는 테스트가 아니다.
- 기본 파일 송신 오류 주입과 cancellation은 준비했다. malloc/모든 open/close 오류 주입, 시그널 발생 시점 전수 조합은 포함하지 않는다. 필요한 기본 오류 검증의 추가 여부를 범위 확정 시 검토한다.
- JPG fixture는 바이트/MIME 전달용이며 이미지 형식 디코딩·브라우저 렌더링은 포함하지 않는다.
- 광범위한 조합/퍼징·악의적 트리 교체·장시간/다중 클라이언트 부하·성능 측정·mmap 비교는 이 범위에서 제외한다.
- 정적 트리 변경 권한은 운영 신뢰 경계다. 스냅샷/악성 콘텐츠 차단을 보장하지 않는다.
- 인코딩 지원과 금지 제어문자 범위를 유지/확대할지는 실행 전에 사용자가 다시 선택한다. 쿼리 정책 변경을 파일 경로에 자동 적용하지 않는다.
## 2026-11-23 공식 기본 검증 실행 결과
사용자가 현재 UTF-8/제어문자 기준 유지와 단위 7개·E2E 3개 실행을 허락했다. 파일 내용/권한 변경은 테스트 전용 임시 fixture로 제한했다.
make test의 7개와 make verify의 3개 스크립트 모두 통과. 실패 0, skip 0. 단위 ASan/UBSan 실행에서 오류 보고 없음. E2E는 -O2 서버다. 종료 후 잔여 server 프로세스 없음.
실제 정적 루트·운영 권한은 변경하지 않았고 실제 권한/ACL 계약 충족은 미검증이다. 광범위한 조합/장애·브라우저 이미지 렌더링·성능은 미검증이다. 정책 변경·성능 측정·커밋/푸시는 하지 않았다.
