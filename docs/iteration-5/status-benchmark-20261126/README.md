## 별도 저부하 strace

각 서버에서 10 제출+10 조회 정상 응답, 기동 확인 TCP 연결 1회. strace -f -c에 포함된 부모·작업자의 recvfrom/epoll_pwait/epoll_ctl 호출 수다. recvfrom에는 클라이언트/백엔드 양쪽 및 기동 연결이 함께 섞여 FD별 분리는 미수행. 전: 8082/691/1473; 후: 101/189/451. 정규화된 총 recvfrom 호출은 전 약404.1회/요청, 후 약5.05회/요청이지만 기동 등 공통 호출을 포함한 근사치. 한 번씩만 조사했고 실행 시간·처리량 비교용이 아니다. strace는 실행을 크게 교란할 수 있다. 원본 syscalls-before.txt/syscalls-after.txt.

CPU profile은 perf 바이너리가 WSL에 없어 미수집. CPU 초/RSS/FD는 1초 표본이며 짧은 peak는 누락 가능하다. 서버별 backend 도착/완료 카운터와 ID 로그, 프로파일은 수집하지 못했다. 로그의 PERCENTILE_US는 wrk의 완료 응답 기준이고 상태·종류별 분리가 아니라 각 시험 요청 종류에 대한 전체 응답 기준이다. 더 자세한 각 반복 상태/지연/자원 및 wrk stderr는 results.json. 종료시 미완료 건수는 별도 계측하지 않아 미상이다.

기능 검증은 기존 make test 통과, make verify의 truncate 기대 200 대 실제 502 실패가 남아 있다. 이번 차이로 안전 보장 또는 최적화 최종 채택을 판단하지 않는다. 추가 성능/원인 분석은 조건·승인 후 진행한다.
