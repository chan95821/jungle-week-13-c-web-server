# 동적 API 확인 기준 — 실행 전 기록

구현 전 확인 항목을 정의한다. 현재 테스트 실행 허락을 의미하지 않는다.

- 정상 GET /api/time의 JSON 정수 시각 및 Content-Length.
- POST a=10&b=20, 입력 순서 변경, 음수/0/정수 경계 및 합계 오버플로우.
- 누락/중복/알 수 없는 키, 빈 값, 잘못된 숫자·percent escape·NUL.
- Content-Type 정상/누락/다른 타입/중복, /echo의 기존 타입 정책 유지.
- form 입력의 부분 수신·헤더와 본문 동반 수신 후에만 계산 실행.
- API별 405+Allow, 기존 정적/Hello/echo의 동작 유지.
- 응답 버퍼 수명과 snprintf 절단 검사, 오류 응답 길이.

상태: 기준 문서화. 기능 테스트/서버 실행/성능 측정은 하지 않는다.
