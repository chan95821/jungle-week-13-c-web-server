# Iteration 1 테스트 문서

설계 단계에서 각 함수별로 도출한 테스트 케이스를 누적 기록한다.

---

## 1. `parse_port(arg, &out_port)`

### 정상 케이스 (성공, 반환값 `0`)

| 입력 (`argv[1]`) | 기대 포트 (`out_port`) | 검증 포인트 |
| --- | --- | --- |
| `"1"` | `1` | 최소 유효 포트 경계값 |
| `"8080"` | `8080` | 일반 개발 포트 |
| `"65535"` | `65535` | 최대 유효 포트 (`uint16_t` 상한) |

### 예외/경계 케이스 (거부, 반환값 `-1`, CLI 실행 시 종료 코드 `1`)

| 입력 (`argv[1]`) | 기대 결과 | 검증 포인트 |
| --- | --- | --- |
| 인자 누락 (`argc != 2`) | Usage 출력 후 종료 코드 `1` | `./server`, `./server 8080 extra` 거부 |
| `""` | 거부 (`-1`) | 빈 문자열 |
| `"0"` | 거부 (`-1`) | `0`번 포트(임시 포트 할당용) 차단 |
| `"-1"` | 거부 (`-1`) | 음수 차단 |
| `"65536"` | 거부 (`-1`) | `uint16_t` 상한(65535) 1 초과 경계값 |
| `"99999999999999999999"` | 거부 (`-1`) | `strtol` 오버플로우(`ERANGE`) 차단 |
| `"80abc"` | 거부 (`-1`) | 숫자 뒤 불필요한 문자(`*endptr != '\0'`) 차단 |
| `"abc"` | 거부 (`-1`) | 비숫자 문자열 차단 |
| `"+8080"` / `" 8080"` | 거부 (`-1`) | 순수 숫자 시작(`isdigit(arg[0])`) 외 입력 차단 |

## 2. `open_listenfd(port)`

### 정상 및 재시작 케이스

| 시나리오 | 기대 결과 | 검증 포인트 |
| --- | --- | --- |
| 사용 가능한 포트(`./server 8080`) 실행 | 리슨 소켓 생성 성공, `127.0.0.1:8080` 접속 가능 | `htons(port)` 바이트 오더 정상 적용 확인 |
| 요청 1회 처리 → 서버 종료 → 같은 포트로 즉시 재실행 | `Address already in use` 없이 즉시 재기동 | `setsockopt(SO_REUSEADDR)` 동작 확인 |

### 실패 및 FD 정리 케이스

| 시나리오 | 기대 결과 | 검증 포인트 |
| --- | --- | --- |
| 동일 포트로 서버 2개 동시 실행 | 두 번째 서버가 `bind` 오류 출력 후 종료 코드 `1`로 종료 | 포트 점유 실패(`EADDRINUSE`) 처리 |
| 권한 없는 특권 포트(`./server 80`, 비루트) 실행 | `bind` 오류 출력 후 종료 코드 `1`로 종료 | `EACCES` 실패 및 열었던 소켓 `close` 정리 |

## 3. `handle_client` (`recv_until_header_end` / `send_all`)

### A. `recv_until_header_end` (단위 테스트 + 소켓 경계)

| 시나리오 | 기대 결과 | 검증 포인트 |
| --- | --- | --- |
| 정상 헤더 1회 수신 (`GET / HTTP/1.1\r\nHost: a\r\n\r\n`) | 성공 (`0`) | 기본 헤더 종료 탐지 |
| 분할 수신 (`...\r\n\r` 후 다음 `recv`에서 `\n` 도착) | 성공 (`0`) | `recv()` 경계에 걸친 `\r\n\r\n` 탐지 |
| 헤더 뒤 본문 동반 (`...\r\n\r\nhello` 1회 수신) | 성공 (`0`) | 끝 4바이트만 비교하지 않고 전체에서 `\r\n\r\n` 탐지 |
| 유사 패턴 (`\n\n`, `\r\n`, `\r\r\n\n`)만 수신 후 `EOF` | 실패 (조기 `EOF`) | 잘못된 구분자를 헤더 끝으로 오인하지 않음 |
| `0`바이트 즉시 연결 종료 (`EOF`) | 실패 (조기 `EOF`) | 응답 없이 안전 종료 |
| `\r\n\r\n` 전 중간 연결 종료 (`GET / HTTP/1.1\r\n` + `EOF`) | 실패 (조기 `EOF`) | 불완전 요청 거부 및 연결 정리 |
| 정확히 `8192`바이트째에 `\r\n\r\n`으로 종료 | 성공 (`0`) | 버퍼 상한 경계값 (`off-by-one` 없음) |
| `8192`바이트 초과까지 `\r\n\r\n` 미도달 | 실패 (상한 초과) | 버퍼 오버플로우 방지 |

### B. `send_all` (단위 테스트)

| 시나리오 | 기대 결과 | 검증 포인트 |
| --- | --- | --- |
| 길이 `0` 송신 | 성공 (`0`) | 빈 송신 경계값 |
| `socketpair` + 작은 `SO_SNDBUF`로 대용량(예: 64KB) 송신 | 성공 (`0`), 수신 데이터 100% 일치 | 커널 부분 송신(`short count`) 반복 루프 검증 |
| 수신 측 먼저 닫힌 소켓에 송신 | 실패 (`-1`), 프로세스 생존 | `SIGPIPE` 무시 + `EPIPE` 오류 반환 확인 |

### C. `handle_client` E2E 통합 검증

| 시나리오 | 기대 결과 | 검증 포인트 |
| --- | --- | --- |
| `curl -i http://127.0.0.1:<port>/` | `HTTP/1.1 200 OK`, `Content-Type: text/plain`, `Content-Length: 5`, `Connection: close`, 본문 `Hello` | DoD 기본 HTTP 응답 규격 |
| 연속 반복 연결 (10회 이상) | 매 요청 동일 정상 응답 | `close(connfd)` 누락 / FD 누수 없음 |
| 응답 수신 중 클라이언트 강제 종료 | 서버 프로세스 생존, 다음 연결 정상 응답 | `SIGPIPE` 내성 및 연결 격리 |
| `SIGINT` (`Ctrl+C`) 수신 | 서버 정상 종료, `listenfd` 해제 | 안전 셧다운 |
